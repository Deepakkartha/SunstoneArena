# SunstoneArena
Sunstone Sports Arena - website

A static, classic-Arizona-themed website for Sunstone Sports Arena, built from the
*Sunstone Sports Arena Master Plan* (65 acres, 10 cricket grounds, covered practice nets,
clubhouse, parking and presentation plaza). No build step: open `index.html` or serve
the folder with any static host (GitHub Pages, Netlify, etc.).

```
python3 -m http.server 8000   # then visit http://localhost:8000
```

## Pages

| Page | File | What it does |
| --- | --- | --- |
| Home | `index.html` | Desert-sunset hero with cricket batting/bowling art, key stats, links to every module, upcoming events |
| 1. About | `about.html` | Vision, master plan at a glance, development phases, **address**, hours, contact, embedded map |
| 2. Field Reservation | `reservations.html` | Hourly pricing (off-peak / peak), add-ons, packages, booking-request form with live estimate |
| 3. Calendar | `calendar.html` | Month view with filters; shows events plus booking requests made in this browser |
| 4. Facility Map | `map.html` | Interactive site plan from the master plan — click any ground or facility for details |
| 5. Event Gallery | `gallery.html` | Filterable picture gallery with a keyboard-accessible lightbox |
| 6. Facility Features | `features.html` | Grounds, pitches, nets, dugouts, clubhouse, plaza and desert-smart design |

## Hosting (GitHub Pages)

`.github/workflows/pages.yml` publishes the site to GitHub Pages on every push to `main`:
**https://deepakkartha.github.io/SunstoneArena/**

If the first run fails at "configure-pages", open the repo's **Settings › Pages** and set
**Source** to **GitHub Actions**, then re-run the workflow. For a custom domain, add it under
Settings › Pages and update the `canonical` / `og:` URLs in each page's `<head>`.

## Editing content

Almost everything you'll want to change is in **`js/site-config.js`**:

- `address`, `phone`, `email`, `hours` — **these are placeholders; replace them with the real details.**
- `fields`, `addOns`, `packages` — reservation pricing (example rates; confirm before launch).
- `events` — calendar entries (`YYYY-MM-DD`, type `tournament | academy | community | maintenance`).

## Images

The illustrations in `images/` are original SVGs generated by `tools/generate_art.py`
(`python3 tools/generate_art.py` to regenerate). To use real event photos, add them to
`images/gallery/` and copy a `<figure>` block in `gallery.html`.

## Booking requests

The site is static, so the booking form doesn't take payment or reserve slots on a server.
On submit it saves the request in the visitor's browser (so it appears on their calendar
as *pending*) and opens a pre-filled email to the bookings address. To take real bookings,
point the form at a form service or booking backend.
